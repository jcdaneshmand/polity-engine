# Fictional Regression Fixtures

This directory contains fictional, public-safe data for Polity Engine regression testing. It must not contain official card names, rules text, nation names, decklists, scans, images, generated private data, or claims about the balance of unavailable content.

Fixture version 3 targets rules version 3. `scenarios.json` is a fail-closed executable catalog: unknown step and check types are errors, every required ID must be present, and full games must reach their declared terminal outcome. Run it with `npm.cmd run scenario:fictional` or through the stronger `npm.cmd run smoke:fictional-game` gate.

## Original Deck Roles

| Nation | Tested role |
| --- | --- |
| Milestone Cooperative | Progression, Nation-card insertion, and separate Action/Exhaust accounting |
| Canal Exchange Union | Trade Routes, finite Goods movement, and Market acquisition choices |
| Wayfinder Assembly | Reactive Exhaust timing, Regions, Garrison, restore, and recall |
| Border Envoy Circle | Human effects directed at the solo Bot |
| Lantern Scorekeepers | Normal endgame timing and independently calculated scoring |
| Last-Straw Assembly | Immediate Collapse and terminal interruption |

| F08-4P | Constructed boundary | Four-player Solstice recipient order |

Full games and executable sequences begin with the production setup pipeline and use production moves and resolvers. They do not mutate state to force an outcome. F08 is deliberately labeled `constructed_boundary`; it clears resource/play areas and places one fictional clock in play to isolate 3-/4-player Solstice ordering.

Expected scores in `scenarios.json` are handwritten arithmetic, not values generated by the scoring function under test. The scenario report includes executed IDs, seeds, checkpoint counts, terminal reasons, expected scores, actual scores, and failures.

The browser setup offers **Load Fictional Playtest Set**. It passes this committed synthetic data through the existing typed bundle path, selects its custom Commons cards, and never reads a private file. These compact decks are correctness fixtures, not balanced substitutes for a complete tabletop collection.
